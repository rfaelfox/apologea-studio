IV · Einstellungen

Schlüssel & Marke

Groq – Text-KI & Spracherkennungkostenlos

Wird für die Konzepte und für den Video-Cutter gebraucht. So bekommst du ihn (2 Minuten, ohne Kreditkarte):

  1. Auf console.groq.com/keys mit Google oder E-Mail anmelden.
  2. „Create API Key“ klicken, einen Namen eingeben (z. B. Apologea).
  3. Den Schlüssel (beginnt mit gsk_) kopieren und hier einfügen.
Cloudflare – Bild-KIkostenlos

Malt deine Motive (ca. 200 Bilder pro Tag gratis, ohne Kreditkarte):

  1. Auf dash.cloudflare.com kostenlos registrieren.
  2. Links „AI“ → „Workers AI“ öffnen, dann „REST API verwenden“ / „Use REST API“.
  3. „Workers AI API-Token erstellen“ klicken und den Token kopieren. Die Konto-ID steht auf derselben Seite.
OpenAI – Premium-Bilderoptional · kostet

OpenAIs beste Bild-KI. Mit Schlüssel erscheint bei jedem Motiv der Knopf „✦ Premium“: Dann wird nur dieses Motiv bei OpenAI gemalt, mit echtem transparentem Hintergrund. Hohe Qualität kostet ca. 5 Cent pro Bild.

Wichtig: Das ChatGPT-Abo zählt hier nicht. Du brauchst einen eigenen Zugang:

  1. Auf platform.openai.com anmelden und unter „Billing“ Guthaben aufladen (z. B. 5 $).
  2. Unter API keys „Create new secret key“ klicken und den Schlüssel (beginnt mit sk-) kopieren.
Fotos für Videoskostenlos

Echte Profi-Fotos zum Einblenden, kostenlos und auch für Werbung erlaubt. Ein Schlüssel reicht, Unsplash hat die schärfsten Bilder.

Unsplash (empfohlen):

  1. Auf unsplash.com/join kostenlos registrieren.
  2. unsplash.com/oauth/applications/new öffnen, alle Haken setzen, „Accept terms“, als Name z. B. „Apologea Studio“ eintragen.
  3. Auf der nächsten Seite den Access Key kopieren.

Pixabay (Alternative):

  1. Auf pixabay.com kostenlos registrieren.
  2. pixabay.com/api/docs öffnen. Unter „Parameters“ steht grün „Your API key“. Den kopieren.
